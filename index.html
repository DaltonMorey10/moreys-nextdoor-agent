Connect Nextdoor account

Setup stage: This starter securely handles the Publishing API OAuth callback. It does not yet search neighborhood posts or automatically publish comments.

What this starter does

  • Starts Nextdoor's authorization flow.
  • Checks the OAuth state to help prevent forged callbacks.
  • Exchanges the authorization code for a token on the server.
  • Encrypts the token before saving it to Supabase.
  • Shows connection status without exposing credentials.

Never share your Nextdoor client secret, Supabase service-role key, or encryption key. Add them only to Vercel environment variables.
